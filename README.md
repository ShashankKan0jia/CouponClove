# CouponClove

CouponClove is a React + TypeScript frontend project built with Vite.

## Stack

- React 18
- TypeScript
- Vite
- React Router
- TanStack React Query
- Tailwind CSS
- Radix UI components
- Recharts
- React Hook Form + Zod
- Lucide React

## Development

Install dependencies and start the Vite development server:

```bash
npm install
npm run dev
```

## Validation

Run the available lint and production build checks:

```bash
npm run lint
npm run build
```

The repository keeps the frontend source under `src/` and uses Vite's standard development and production workflow.
