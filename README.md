# CouponClove

A React + TypeScript frontend project built with Vite.

## Stack
React 18, TypeScript, Vite, React Router, TanStack React Query, Tailwind CSS, Radix UI, Recharts, React Hook Form, Zod, and Lucide React.

## Development
`npm install`
`npm run dev`

## Validation
`npm run lint`
`npm run build`

The main application source lives under `src/`.
